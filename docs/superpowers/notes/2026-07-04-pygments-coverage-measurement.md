# Замер охвата через Pygments и расширение перехвата

Дата: 2026-07-04. Ветка: `feat/file-mapping-tab-redesign`. Коммит: `b99f2fd`.

## Зачем

Пользователь: вкладка «Просмотр в Finder» должна давать максимум — добавил пару
«расширение → грамматика», и файл этого расширения показывается по пробелу. Узкое место —
**перехват** (долетит ли файл до расширения), а не наличие грамматики по умолчанию: грамматику
приносит сам пользователь (существующая из 218 или импорт `.vsix`). Значит нужно расширить
набор расширений, которые мы перехватываем.

Источник расширения охвата — **только Pygments** (скрейпинг VS Code отвергнут ранее). Сначала
измерить, потом вливать.

## Метод

1. `pygments 2.20.0` в venv → `get_all_lexers()` даёт `(name, aliases, filenames, mimetypes)`;
   из `filenames` берём одно-сегментные `*.ext` → `ext`.
2. Текущий охват — расширения из `associations.json` (linguist + overrides): **815**.
3. Недостающие Pygments-расширения прогнать через `UTType(filenameExtension:)` и разбить:
   `dyn` (система не знает → берём своим экспортным UTI без коллизий) / системный текст /
   «ложный друг» (система метит не-кодом — трогать нельзя).

Скрипты замера — в скретчпаде сессии (не в репозитории): `measure.py`, `uti436.swift`,
`build_edits.py`.

из 436 у 401 грамматики нет, но для перехвата это неважно — язык пользователь назначит сам.

### 13 «ложных друзей» (намеренно НЕ объявлены)

`arw`,`mos` (RAW-фото) · `dot` (шаблон Word) · `dts`,`xm` (аудио) · `eml`,`mhtml` (почта/MIME) ·

файлы. Как `.ts`/`.r`/`.as`, брать можно только поимённо и осознанно.

### 11 артефактов лексеров (санитайзер выкинул)

файлов, а имена дампов/сессий Pygments. Фильтр: `^[a-z0-9_][a-z0-9_.]*$`.

## Что изменено (развязка перехвата от языка)

Перехват и «грамматика по умолчанию» — **разные заботы**. Прежде они были склеены: генератор
(`generate-associations.mjs:72 if (shikiIds.has(id))`) и аудит выкидывали любое расширение, у
языка которого нет грамматики. Развязал:

- `associations-overrides.json`: ключ `interceptExtensions` (389 без грамматики → нейтральный
  показ до правила пользователя) + 16 уверенных дефолтов Pygments с грамматикой
  (`gradle`→groovy, `ndjson`→json, `pom`→xml, `bzl`/`sage`/`jy`/`pye`→python, `eex`/`leex`→elixir,
  `mxx`→cpp, `duby`→ruby, `rakudoc`/`rakutest`→raku, `xbrl`→xml, `dax`→dax, `csh`/`tcsh`→shellscript).
- `generate-associations.mjs`: пробрасывает `interceptExtensions` в `associations.json`
  (исключая уже owned языком). Потребители (`FileTypeAssociations` Swift, js-смоук) неизвестный
  ключ игнорируют — правок не потребовалось.
- `audit-extension-utis.swift`: читает `interceptExtensions`, помечает `→(intercept)`,
  включает в `--emit-tags`.
- `project.yml`: `UTExportedTypeDeclarations` хоста **654→1057** расширений; в
  `QLSupportedContentTypes` расширения добавлены `public.csh-script`/`public.tcsh-script`/
  `public.ndjson` (системный текст, мимо dyn-UTI). `public.php-script` уже был → `phtml` покрыт.

## Грабля: самоконтаминация при пересборке списка

Список 1057 влит **объединением** (текущие 654 ∪ новые 403), а НЕ пересобран
`--emit-tags` на этой машине. После сборки и регистрации нашего UTI уже объявленные 654
расширения `UTType` резолвит в `com.quicklookers.source-code` (не `dyn`) → полный `--emit-tags`
их бы потерял. Новые 403 ещё чистые dyn, потому добавляются к существующему. На **чистой**
машине (ничего нашего не зарегистрировано) `--emit-tags` резолвит все в dyn и воспроизводит
полный 1057 — ради этой воспроизводимости и правки в генератор/аудит. Живое подтверждение
контаминации: после сборки аудит показал `agda`/`abnf`/`1p` → `com.quicklookers.source-code`.
